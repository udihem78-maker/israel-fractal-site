### 8 פרקי החובה
1. **Abstract** (150-250 מילים · 5 keywords)
2. **Introduction** (1-1.5 עמוד · 3 שאלות מחקר · 2-3 היפותזות)
3. **Literature review** (2-3 עמ' · 15-25 מקורות)
4. **Methods** (3-5 עמ' · הנוסחה F=D×U/R מבוססת מתמטית · 125K נ"מ)
5. **Data sources** (2 עמ' · 40 מקורות ראשוניים · טבלה)
6. **Results** (5-10 עמ' · 8-10 גרפים · טבלאות)
7. **Discussion** (3-4 עמ' · מגבלות · relevance)
8. **Conclusion + Future work** (1 עמ')
9. **References** (40-60 bibliography · APA 7)
10. **Appendices** (data tables · code links · reproducibility notes)
